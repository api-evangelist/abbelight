# Abbelight

> Abbelight is a French bioimaging company (founded 2016, Cachan, Île-de-France) that builds
> single-molecule localization microscopy and nanoscopy instrumentation. Its modular SAFe platform
> mounts on the camera port of any inverted microscope and upgrades it from widefield and TIRF to
> super-resolution imaging (STORM, PALM, DNA-PAINT, spectral demixing). Abbelight publishes no
> public API, SDK, developer portal or machine-readable specification.

## Status for machine consumers

- No public API. As of 2026-09-05 no OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract is
  published on any host this company controls (abbelight.com, www.abbelight.com, shop.abbelight.com).
- No /.well-known/ discovery surface. All 15 named discovery paths return 404 on all three hosts,
  including /.well-known/agent-card.json, /.well-known/agent.json, /apis.json and /llms.txt.
- No MCP server, no A2A agent card, no published SDK on npm, PyPI, RubyGems or crates.io.
- The only machine-readable surface reachable at all is the default WordPress REST API at
  shop.abbelight.com/wp-json/, and anonymous requests to it return 401 rest_not_logged_in.
- Products are sold through account executives and a WooCommerce consumables shop, not self-service
  API signup. Software is shipped as the desktop SAFe Neo analysis suite, not as a service.
